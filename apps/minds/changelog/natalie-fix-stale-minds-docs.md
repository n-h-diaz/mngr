Corrected Imbue Studio docs that had drifted from the code. The minds style guide no longer grants an async exception "since we use FastAPI": the desktop client is now a synchronous Flask app, so the root sync-only rule applies unchanged. The testing overview and the e2e README now list all three Playwright specs (`macos-launch`, `macos-lifecycle`, `context-menu`) instead of calling `macos-launch` the only one, and note that only `macos-launch` runs in CI. The getting-started URLs and the security audit's superseded banner now use the agent-keyed `[<label>.]agent-<hex>.localhost` origins the forward proxy actually serves, and the getting-started and workspace docs show the current `<share-label>.<user-hash>` share-domain shape instead of the legacy host-id one. Getting started and the design doc also list the current launch modes (there is no `CLOUD` mode; it is `VULTR`). The README no longer says every agent runs in a Docker container, since workspaces can also run in a Lima VM or on a cloud host. The security audit's banner also notes the desktop client is now Flask rather than FastAPI.
