Corrected Imbue Studio docs that had drifted from the code. The minds style guide no longer grants an async exception "since we use FastAPI": the desktop client is now a synchronous Flask app, so the root sync-only rule applies unchanged. The testing overview and the e2e README now list all three Playwright specs (`macos-launch`, `macos-lifecycle`, `context-menu`) instead of calling `macos-launch` the only one, and note that only `macos-launch` runs in CI. The getting-started URLs and the security audit's superseded banner now use the agent-keyed `[<service>.]agent-<hex>.localhost` origins the forward proxy actually serves (`host-<hex>` remains the host id and the share-domain key, and is unchanged where it means that). The README no longer says every agent runs in a Docker container, since workspaces can also run in a Lima VM or on a cloud host.
